      Hướng dẫn vận hành file Detail_information & MCL

      Dành cho người dùng thao tác hằng ngày: gán KEYS cho dự án, tạo file MCL và nạp dữ liệu. Mọi thao tác đều làm trên Google Trang tính qua menu AMECC, không cần đụng vào code.

      Tổng quanMột file Detail_information quản lý danh sách dự án, mỗi KEYS sinh ra một file MCL riêng.

      Nhập KEYS MCL (cột D)→ AMECC → Tạo link→ File MCL_<KEYS> + link ở cột E→ AMECC → Nạp dữ liệu→ Dữ liệu vật tư trong file MCL

      KEYS MCL là mã nhóm do bạn tự đặt (ví dụ 1, 2). Các dự án có cùng KEYS sẽ dùng chung một file MCL. File được đặt tên MCL_<KEYS>, ví dụ MCL_1.

      Các cột trong sheet Detail_information

      Dòng 1–3 là tiêu đề, dữ liệu bắt đầu từ dòng 4.

      CộtNội dungAi điền
      A–CNo., Project, Project NameTự động từ hệ thống
      DKEYS MCLBạn nhập
      ELINK – link file MCLMenu AMECC tự điền
      FLink folder tài liệuBạn nhập
      G–SClient, PO Sign, Contract No … Port ArrivalTự động từ hệ thống

      Các cột bạn nhập (D, F, T–AA) luôn được giữ nguyên khi hệ thống cập nhật, kể cả khi bạn sắp xếp lại bảng. Dự án mới được thêm vào cuối bảng.

      Luồng 1 · Tạo file MCL cho KEYS mớiDùng khi có dự án chưa được gán vào file MCL nào.

      1

      Nhập KEYS ở cột D

      Mở file Detail_information, tìm các dự án cần tạo MCL và gõ KEYS vào cột D – KEYS MCL. Dự án nào muốn chung file thì nhập cùng một KEYS. Để trống cột E – LINK.

      2

      Chọn AMECC → Tạo link cho KEYS chưa có link

      Trên thanh menu, bấm AMECC rồi chọn Tạo link cho KEYS chưa có link. Nếu chưa thấy menu AMECC, nhấn F5 và chờ vài giây.

      3

      Kiểm tra link vừa tạo

      Chờ thông báo ở góc dưới bên phải. Sau đó cột E – LINK có link file MCL, các dòng cùng KEYS có cùng một link. Trong thư mục Drive xuất hiện file mới MCL_1, MCL_2.

      4

      Chọn AMECC → Nạp dữ liệu MCL (tất cả key)

      File MCL mới tạo chưa có dữ liệu. Bấm AMECC → Nạp dữ liệu MCL (tất cả key) để đổ dữ liệu vật tư vào các file, rồi chờ thông báo.

      5

      Mở file MCL để kiểm tra

      Bấm link ở cột E. Trong file MCL, ô D2 liệt kê các mã dự án thuộc KEYS đó, dữ liệu bắt đầu từ dòng 6.

      Luồng 2 · Thêm dự án vào KEYS đã cóDùng khi một dự án mới cần đưa vào file MCL đang dùng.

      Nhập KEYS cũ ở cột D→AMECC → Tạo link→AMECC → Nạp dữ liệu
      • Nhập KEYS đã có (ví dụ 1) vào cột D của dự án mới.
      • Chọn AMECC → Tạo link cho KEYS chưa có link. Hệ thống không tạo file mới, chỉ điền link file cũ vào dòng đó và cập nhật danh sách mã dự án ở ô D2 của file MCL.
      • Chọn AMECC → Nạp dữ liệu MCL (tất cả key) để thêm dữ liệu của dự án mới vào file.
      Muốn chuyển một dự án sang KEYS khác: sửa KEYS ở cột D, xoá ô LINK (cột E) của dòng đó, rồi làm lại 2 bước menu như trên.

      Luồng 3 · Chỉ cập nhật dữ liệuKEYS không thay đổi, chỉ cần lấy dữ liệu mới nhất vào các file MCL.

      AMECC → Nạp dữ liệu MCL (tất cả key)

      Chọn AMECC → Nạp dữ liệu MCL (tất cả key). Mọi file MCL được cập nhật cùng lúc: dòng đã có được cập nhật tại chỗ, dòng mới thêm vào cuối, cột bạn nhập tay giữ nguyên.

      Lịch tự động cập nhật định kỳ cho Detail_information và các file MCL đang được triển khai. Khi hoàn tất, bạn không cần bấm nạp dữ liệu nữa, trừ khi muốn lấy dữ liệu ngay lập tức.

      Làm việc trên file MCL

      • Cột lấy từ hệ thống sẽ được ghi lại mỗi lần nạp dữ liệu. Nếu sửa tay, giá trị của bạn sẽ bị thay bằng dữ liệu hệ thống.
      • Cột nhập tay luôn được giữ nguyên và đi theo đúng dòng của nó.
      • Cột Q'ty Must Order là công thức, đừng gõ đè số vào.
      • Sắp xếp: phải chọn cả bảng rồi mới sắp xếp. Sắp xếp riêng vài cột sẽ làm lệch dữ liệu nhập tay.
      • Lọc: nên dùng Dữ liệu → Tạo chế độ xem bộ lọc. Cách này không ảnh hưởng tới người khác đang xem file.
      • Không xoá cột khoá ẩn ở cuối bảng. Đây là cột hệ thống dùng để nhận ra từng dòng.
      • Dòng bị xoá tay sẽ được thêm lại ở cuối bảng trong lần nạp dữ liệu sau.

      Dòng bị bỏ qua do trùng

      Nếu nhiều dòng vật tư trùng nhau (cùng Project, MPR No., No., Size và Net Weight), hệ thống bỏ qua cả nhóm để tránh ghi sai, và ghi lại vào tab MCL_Trung_Key trong file Detail_information. Bạn xem tab này sau mỗi lần nạp và báo người phụ trách nếu cần xử lý.

      Những điều không nên làm

      • Đổi tên tab Detail_information, hoặc sửa / xoá tab Key_Map. Đây là sổ đăng ký KEYS và file MCL.
      • Tự gõ hoặc dán link vào cột E – LINK. Hãy để menu AMECC điền.
      • Xoá, đổi tên hoặc di chuyển file MCL ra khỏi thư mục Drive.
      • Chèn hoặc xoá cột trong Detail_information và các file MCL.
      • Bấm menu nhiều lần liên tiếp khi lần trước chưa báo xong.
